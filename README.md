# Bewerbung Wagner Solar

Unternehmensspezifische Bewerbungswebsite von Sascha Boss für die Position als Mediendesigner bei Wagner Solar.

## Inhalt

- zielgerichtete One-Page-Bewerbung
- integrierter Lebenslauf unter `/lebenslauf/`
- responsive Umsetzung in reinem HTML, CSS und JavaScript
- GitHub-Pages-Konfiguration für `bewerbung-wagner-solar.saschaboss.de`

## Lokale Vorschau

```bash
python3 -m http.server 8080
```

Anschließend `http://localhost:8080` im Browser öffnen.
